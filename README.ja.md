# ipsj-words

情報処理学会（IPSJ）による日本語のITおよび情報科学の用語集。CSVファイルおよび検索可能なWebアプリケーションとしてパッケージ化されています。

## デモ

[**IT辞書**](https://code4fukui.github.io/ipsj-words/)

用語リストを検索・閲覧できるシンプルなシングルページWebアプリケーションです。

## 機能

- **ライブ検索:** 入力と同時に用語と説明を即座に検索します。
- **インタラクティブな説明:** 説明文内のキーワードがハイパーリンク化されており、関連用語へジャンプできます。
- **ランダム表示:** 「ランダム」ボタンで新しい用語を発見できます。
- **スタンドアロン:** サーバーサイドの依存関係がない単一のHTMLファイルで構成され、`IndexedCache.js`を使用してローカルデータへ高速にアクセスします。

## 使い方

1. [デモサイト](https://code4fukui.github.io/ipsj-words/)にアクセスします。
2. 検索ボックスにキーワードを入力してリストを絞り込みます。
3. 「ランダム」ボタンをクリックしてランダムな用語を表示します。
4. 説明文内の太字のキーワードをクリックしてその用語を検索します。

## データ

用語データは単一のCSVファイルとして提供されています:
- [`ipsj-words-ver.1.0_2024-4-10.csv`](ipsj-words-ver.1.0_2024-4-10.csv)

ファイルには以下の主要フィールドが含まれます:
- `用語`: 日本語の用語。`|`で区切られた表記揺れを含む場合があります。
- `説明`: 用語の説明。

その他の列には、カテゴリ、コード、各種教科書での掲載率などのメタデータが含まれています。

このデータは、[情報処理学会 情報入試委員会 - 情報科全教科書用語リスト](https://sites.google.com/a.ipsj.or.jp/ipsjjn/wordlist) のものであり、CC 4.0 BY-SAライセンスの下で提供されています。
